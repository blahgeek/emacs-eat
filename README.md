# About this fork

[Original README](./README.orig.org)

This is a fork of https://codeberg.org/akib/emacs-eat

Apparently the original author has been inactive since about Feb 2025. I use EAT heavily everyday. There are several important fixes submitted to upstream (by myself and others) but got no response, so here's my own maintained fork.

Goal of the fork: **No new features, only bug fixes**

Here's the list of changes: [compare](https://github.com/blahgeek/emacs-eat/compare/master...dev)

- [fix CSI cursor position save/restore functions not being matched](https://codeberg.org/akib/emacs-eat/pulls/231) by @Uthar
